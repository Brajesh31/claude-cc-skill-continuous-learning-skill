# Cc Skill Continuous Learning

Development skill from everything-claude-code

## Overview

This repository preserves the AITMPL skill instructions and its published companion resources.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-cc-skill-continuous-learning-skill.git ~/.claude/skills/cc-skill-continuous-learning
```

On Windows, use `%USERPROFILE%\.claude\skills\cc-skill-continuous-learning` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/cc-skill-continuous-learning` when needed.
